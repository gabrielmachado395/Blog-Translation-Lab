# Meu primeiro artigo estatico

Este artigo existe como arquivo Markdown dentro do projeto. Ele serve para estudar a diferenca entre traduzir conteudo estatico e traduzir conteudo criado por CRUD.

## O que observar

Quando este arquivo for traduzido, vale conferir se os links, titulos e blocos de codigo continuam organizados.

```ts
const locale = "pt-BR";
console.log(`Idioma fonte: ${locale}`);
```

O bloco acima deve ser preservado sem traducao automatica.
